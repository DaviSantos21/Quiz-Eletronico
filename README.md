# Electronic Quiz System

Sistema de quiz eletrônico desenvolvido utilizando ESP32, com o objetivo de proporcionar uma experiência interativa de aprendizagem e autoavaliação de conhecimentos.

## Objetivo

Desenvolver um sistema embarcado capaz de apresentar perguntas e alternativas, permitir a interação do participante por meio de botões físicos e apresentar os resultados ao final de uma partida.

## Funcionalidades principais

- Exibição de perguntas e alternativas.
- Seleção de respostas por botões físicos.
- Navegação entre perguntas.
- Verificação das respostas.
- Cálculo da pontuação.
- Apresentação dos resultados finais.
- Reinício de uma partida.

## Tecnologias e ferramentas

- **Microcontrolador:** ESP32
- **Linguagem:** C++
- **Framework:** Arduino
- **Ambiente de desenvolvimento:** VS Code
- **Extensão:** PlatformIO
- **Versionamento:** Git e GitHub
